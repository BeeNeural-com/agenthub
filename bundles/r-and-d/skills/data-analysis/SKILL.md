# Data Analysis

Turn raw experiment or measurement data into actionable conclusions.

## When to Use

- After running an experiment or benchmark
- Interpreting prototype-spike results
- Supporting feasibility or trade-study decisions with quantitative evidence

## Procedure

### Step 1: Understand the data

- Source, collection method, time range
- Sample size and missing values
- Units and definitions

### Step 2: Clean and summarize

- Remove or flag outliers (document why)
- Compute descriptive stats: mean, median, std dev, min, max
- Group by relevant dimensions

### Step 3: Visualize

Choose appropriate charts:
- Distributions → histogram, box plot
- Comparisons → bar chart, grouped bars
- Trends → line chart
- Relationships → scatter plot

### Step 4: Interpret

- Compare against success criteria from experiment-design
- State statistical vs practical significance
- Note limitations (small sample, confounders)

### Step 5: Conclude

Link findings to the original hypothesis. Recommend proceed, iterate, or stop.

## Output

Include tables or chart descriptions in the research report. Save raw data separately.
