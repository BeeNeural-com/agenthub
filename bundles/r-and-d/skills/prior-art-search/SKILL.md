# Prior Art Search

Identify existing patents and publications that overlap with your concept.

## Disclaimer

This skill supports R&D awareness only. It is **not legal advice**. Consult qualified IP counsel for FTO or filing decisions.

## When to Use

- Before investing in a novel algorithm or interface
- Assessing differentiation for a new feature
- Input for ip-landscape and architecture decisions

## Procedure

### Step 1: Define the invention

- Core inventive concept (1–3 sentences)
- Key technical features (bullet list)
- Alternative embodiments

### Step 2: Build search queries

- Keywords and synonyms
- IPC/CPC classification codes (if known)
- Inventor/assignee names (competitors)

### Step 3: Search databases

- Google Patents, Espacenet, USPTO
- Academic: Google Scholar, IEEE
- Internal: prior internal filings, design docs

### Step 4: Screen results

For top 10–20 hits record:
- Title, number, date, assignee
- Relevant claims or abstract excerpt
- Overlap assessment: high / medium / low / none

### Step 5: Summarize

- Closest prior art
- Differentiation opportunities
- Recommended follow-up (legal review, design-around, further search)
