# Trade Study

Compare alternatives objectively using weighted criteria and documented rationale.

## When to Use

- Multiple viable options after technology scouting
- Architecture or design fork decisions
- Vendor or platform selection
- Input for feasibility study recommendations

## Procedure

### Step 1: Define alternatives

List 2–5 distinct options. Include a baseline ("do nothing" or current state) when relevant.

### Step 2: Define criteria

Pick 5–8 criteria aligned to project goals. Assign weights summing to 100%.

Common criteria: performance, cost, maintainability, time-to-market, risk, scalability, compliance.

### Step 3: Score each alternative

Use 1–5 scale per criterion. Document evidence for each score.

### Step 4: Sensitivity analysis

Vary top-weighted criteria ±20%. Check if the winner changes.

### Step 5: Recommendation

State winning alternative, margin, and conditions under which another option would win.
