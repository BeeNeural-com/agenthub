# Innovation Ideation

Generate and evaluate new ideas with structured creativity and TRL scoring.

## When to Use

- Early-stage concept exploration
- Innovation workshops or roadmap input
- Prioritizing R&D backlog candidates
- Pair with innovation-lead agent

## Procedure

### Step 1: Frame the challenge

- Target user or system
- Constraints (regulatory, technical, budget)
- Success criteria for a "good idea"

### Step 2: Diverge

Generate 10+ ideas using:
- Problem inversion
- Analogies from other industries
- Combining existing capabilities
- Removing constraints temporarily

Do not evaluate during this phase.

### Step 3: Cluster and select

Group similar ideas. Shortlist top 3–5 using:
- Impact (user/business value)
- Novelty
- Feasibility gut-check

### Step 4: TRL assessment

For each shortlisted idea assign TRL 1–9 with evidence:

| TRL | Stage |
|-----|-------|
| 1-2 | Basic research, concept formulated |
| 3-4 | Proof of concept, lab validation |
| 5-6 | Prototype in relevant environment |
| 7-9 | System demo, qualified, operational |

### Step 5: Next actions

For each idea: spike, research, defer, or kill — with owner and timeline.
