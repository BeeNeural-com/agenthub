# Experiment Design

Define experiments that produce trustworthy, reproducible evidence.

## When to Use

- Before a prototype-spike with measurable outcomes
- Validating a technical hypothesis
- Benchmarking alternatives
- Lab or field validation studies

## Procedure

### Step 1: Hypothesis

State as: "If [change], then [measurable outcome], because [rationale]."

### Step 2: Variables

- **Independent:** what you manipulate
- **Dependent:** what you measure
- **Controlled:** held constant
- **Confounding:** identify and mitigate

### Step 3: Method

- Sample size or iteration count
- Environment (hardware, data set, config)
- Procedure steps (reproducible)
- Baseline for comparison

### Step 4: Success criteria

Define pass/fail thresholds before running. Avoid moving goalposts.

### Step 5: Logging

Follow **experiment-logging** rule. Record raw data, config, and anomalies.

Use `references/experiment-plan.md`.
